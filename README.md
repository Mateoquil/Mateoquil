Currently working on:
- 📌 **glass-pins**  
  Social board platform (Pinterest-style) — in early development.  
  Backend: Node.js, Express, TypeScript, Prisma. Frontend: HTML/CSS/Bootstrap.  
  👉 https://github.com/Mateoquil/glass-pins

- 🛒 **POS Inventory System**  
  Backend system with Node.js, Express and MySQL for managing products and sales, integrated with a JWT authentication service.  
  👉 https://github.com/Mateoquil/pos-inventory-system

- 🔐 **POS Auth Module**  
  JWT authentication and role-based access control (RBAC) service, tested with Jest/Supertest.  
  👉 https://github.com/Mateoquil/pos-auth-module
